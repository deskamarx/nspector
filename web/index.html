Finding types

How this is meant to be used

Each finding is a reporting item, not an accusation. A duplicate is almost always an unclosed return, not theft. What matters is that somebody is accountable for closing it.

  • Open — generated, nobody has looked at it
  • Investigating — someone is checking it against the physical unit
  • Resolved — action taken, note recorded against the finding
  • Dismissed — checked and explained, no action needed
